Escanear y Buscar Nuevos Alumnos

El motor de escaneo se conecta en vivo a TusClases (ES, AR, CL, CO, MX, PE), Tablón de Anuncios, Cronoshare y Reddit, filtrando las ofertas docentes con Google Gemini 3.5/3.6 Flash (con respaldo en Groq, Cloudflare y Mistral).

⚡ ¿Cómo ejecutar el escaneo desde tu entorno?

  1. Abre la carpeta del proyecto en tu terminal o consola y ejecuta:
    python main.py run
  2. En Windows también puedes abrir la carpeta del proyecto y ejecutar bin/actualizar_alumnos.bat.
  3. En Linux / macOS puedes ejecutar bash bin/actualizar_alumnos.sh.
  4. El pipeline rastreará los portales clasificados, auditará con IA y actualizará los prospectos conservando el estado de tu CRM.
Pipeline automatizable con cron, Windows Task Scheduler o GitHub Actions.
